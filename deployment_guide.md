# Manual Deployment Guide: Hosting on Render.com

This guide provides instructions to deploy the **Smart Driver Drowsiness Detection System (SDDDS)** to Render.com manually without using Blueprints.

The deployment consists of two phases:
1. **Backend Web Service**: Running the Python Flask server inside a Docker container (this automatically installs all system requirements for OpenCV and MediaPipe).
2. **Frontend Static Site**: Building and serving the React Vite application.

---

## Prerequisites
* A [GitHub](https://github.com) account with your project repository pushed.
* A [Render.com](https://render.com) account.

---

## Phase 1: Deploy the Backend Web Service

We deploy the Python backend inside a Docker container. Render will automatically build the `backend/Dockerfile` we created.

1. Log in to the [Render Dashboard](https://dashboard.render.com).
2. Click **New +** in the top right and select **Web Service**.
3. Select and connect your GitHub repository.
4. Configure the Web Service settings:
   * **Name**: `sddds-backend`
   * **Region**: Choose the region closest to you.
   * **Branch**: `main`
   * **Runtime**: Select **Docker**.
5. Click **Advanced** to configure the folder settings:
   * **Docker Path**: `backend/Dockerfile`
   * **Docker Context**: `.`
6. In the **Advanced** section, add the following configurations:
   * **Add Environment Variable**:
     * Key: `DATABASE_PATH`
     * Value: `/app/db_volume/drowsiness_system.db`
   * **Add Persistent Disk**:
     * Name: `db-volume`
     * Mount Path: `/app/db_volume`
     * Size: `1 GB`
7. Select the **Free** instance plan and click **Create Web Service**.
8. Wait for the build to complete. Once finished, copy the **live URL** of your backend (e.g., `https://sddds-backend-xxxx.onrender.com`) shown at the top left of the service page.

---

## Phase 2: Deploy the Frontend Static Site

We deploy the React frontend as a Render Static Site.

1. Return to the Render Dashboard, click **New +** and select **Static Site**.
2. Connect your GitHub repository.
3. Configure the Static Site settings:
   * **Name**: `sddds-frontend`
   * **Branch**: `main`
   * **Root Directory**: `frontend` *(Important: this directs Render to build from within the frontend folder)*
   * **Build Command**: `npm install && npm run build`
   * **Publish Directory**: `dist`
4. Under the **Environment** tab:
   * Click **Add Environment Variable**:
     * Key: `VITE_API_BASE`
     * Value: `https://your-backend-url.onrender.com` *(Paste the live backend URL you copied in Phase 1)*
5. Click **Create Static Site**.

## Option 2: Real-Time Zero-Lag Webcam Streaming (Local Backend + ngrok)

If you require buttery-smooth local webcam processing at 30 FPS without cloud CPU bottlenecks or network delays:

1. **Run the Backend Locally**:
   * Open your terminal in the project directory.
   * Run the Python backend:
     ```bash
     cd backend
     # Make sure your virtual environment is active (e.g., venv\Scripts\activate)
     python app.py
     ```
   * It will run on `http://localhost:5000`.

2. **Expose Backend via ngrok**:
   * Download and launch [ngrok](https://ngrok.com).
   * Expose your local port `5000` to a secure public URL:
     ```bash
     ngrok http 5000
     ```
   * Copy the generated HTTPS forwarding URL (e.g., `https://abcdef123.ngrok-free.app`).

3. **Configure Render Frontend**:
   * Log in to the [Render Dashboard](https://dashboard.render.com) and click on your **sddds-frontend** Static Site.
   * Go to the **Environment** tab.
   * Update `VITE_API_BASE` value to your **ngrok URL** (e.g., `https://abcdef123.ngrok-free.app`).
   * Save changes and trigger a manual redeploy of the static site.

4. **Verify Zero-Lag Streaming**:
   * Open the public Render frontend URL in your browser.
   * Log in as a driver, pair the webcam, and start monitoring. Your local webcam will open instantly and process frames at 30 FPS, while syncing status updates and incidents live to the cloud database for owners to view from anywhere!
